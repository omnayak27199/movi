# VANAR: WILD CODE — Character Reference Prompt Pack
**Revision:** v0.1  
**Purpose:** Generate consistent turnaround/reference sheets before episode shot generation.  
**Status:** Prompt pack only; reference images have not been generated or approved.

## Shared generation instructions

Use one character per image. Request a clean neutral studio/reference background, full-body front view, three-quarter view, side view, back view, and three face expressions in a clearly arranged character sheet. Keep anatomy, fur pattern, clothing, accessories, age, proportions, and colors identical across views. No text labels inside the image unless the image system can render them reliably; add labels afterward in the asset pipeline. Do not mix characters or environments into reference sheets.

**Shared style suffix:** “high-end cinematic stylized-realistic 3D animation character design, expressive but anatomically coherent face, detailed groomed fur, believable fabric and utility materials, production-ready clean lighting, neutral grey-green studio background, consistent proportions across views, no extra limbs or fingers, no costume variation, no weapons unless specified, no text, no watermark, 16:9 character reference sheet.”

## Asset approval gate

Before any episode shots use generated designs:
1. Generate one candidate sheet per character.
2. Review all views for visual consistency and accidental costume/anatomy changes.
3. Select and freeze one approved reference per character.
4. Store approved image, prompt, provider/model, generation date, usage terms, and approval status in the asset registry.
5. Use the same approved references for every shot; revise the reference only through an explicit design-change decision.
